# 👨🏻‍💻 Lester Osana | Full-Stack Developer
A modern, responsive personal portfolio website built with TypeScript, showcasing my work, experience, projects, and contact information.

## Live Site
- https://osana-dev-portfolio.vercel.app

## Overview
This repository contains the source code for my developer portfolio. The final version includes:
- A fixed, responsive navbar with scroll-based active section tracking, a scroll progress indicator, and a frosted glass background
- Desktop navigation with an animated active-link indicator, plus a mobile hamburger menu with staggered entrance animations
- A theme toggle powered by `next-themes`, with full light/dark support across the navbar and hero section
- A polished logo/name treatment with hover reveal interaction
- Smooth scrolling to section anchors
- A hero section with a status badge, gradient name treatment, animated profile photo ring, dual call-to-action buttons (Projects + Resume), and a scroll-down indicator
- An about section with icon-labeled focus area cards, a quick facts grid, and a categorized tech stack (Frontend, Backend, Database, Tools)
- An experience section with icon-tagged tabs (Work, Education, Certifications, Trainings) and a timeline-style layout for entries
- A projects section with image banner previews for each project, floating link icons, and hover zoom effects
- A contact section with a card-based layout, icon-prefixed form inputs, and animated, accessible status feedback
- A downloadable resume link
- Motion-powered UI transitions and interactive hover states throughout

## Tech Stack

## Features
- Mobile-first, responsive layout across all sections

## Getting Started
Clone the repository and install dependencies:
```bash
npm install
npm run dev
```
Then open the local development server in your browser.
